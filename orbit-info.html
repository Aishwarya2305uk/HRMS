What Orbit is

Orbit is a single-page web app where everyone in the company signs in to one portal. What you see is decided by your role — the same shell shows an employee their timer, leaves and calendar; a manager additionally gets approvals and announcements; an admin gets the full people, policy and settings toolkit. Every permission is enforced on the server, not just hidden in the UI.

⏱

Attendance

A Zoho-style check-in timer records your day from server-side events: check in, pause for breaks, resume, check out. The timer survives refreshes and re-logins because elapsed time is always computed on the server.

🌿

Leave management

Apply for leave (or work-from-home) with type, dates and reason. Requests go to your immediate manager, balances are deducted only on approval, and results land on your dashboard and the company calendar instantly.

📣

Announcements & notifications

Admins and managers compose announcements — company-wide, per role, to a reporting subtree, or to custom teams. Everyone gets a notifications feed plus a quick-glance bell drawer, with unread badges in the sidebar.

🏢

Organization visibility

The org tree is built purely from each person's immediate manager and updates the moment the admin adds or reassigns someone. Nodes show live presence — online, idle, or offline — derived from today's timer activity.

The three roles

Managers are also employees — every capability below stacks on top of the previous role's.

Everyone

Employee

  • Check in / pause / resume / check out on the dashboard timer
  • Apply for leave and work-from-home; track Pending / Approved / Rejected
  • See remaining balance per leave type
  • Personal attendance history with daily verdicts
  • Notifications feed, leave calendar, profile with documents
  • Feedback & HR Request forms from the sidebar

+ Direct reports

Manager

  • Approvals queue for direct reports only — approve or reject with a comment
  • Compose announcements to their own reporting subtree
  • Create named teams (subsets of their subtree) for finer targeting
  • Manage sent announcements and see read state

+ Whole company

Admin

  • People roster: add employees with role, department, joining date and manager
  • Reassign managers (cycle-safe) — this is what shapes the org tree
  • All leaves & all attendance, company-wide, month by month
  • Leave Policies: manage leave types, quotas and employment types
  • Other Settings: org-wide Feedback / HR Request form links
  • Company-wide and per-role announcements

How a workday is recorded

Signing into the app never marks attendance — only the timer does. One work session exists per person per day, stored as an ordered event log.

1 · CHECK INStart your dayThe timer starts from this moment.
2 · PAUSE / RESUMEBreaks don't countPause any number of times; paused minutes are never worked time.
3 · CHECK OUTEnd your dayWorked time = the sum of all running intervals.
4 · AUTO-CLOSEForgot to check out?The day finalizes itself at midnight with whatever was recorded.
The 8-hour rule: when a day closes, ≥ 8 recorded hours marks it Present and anything less automatically marks it Auto-leave — reflected in history, dashboards and the calendar. The threshold lives in one config value, not scattered through the code.

The workspace

🧭

Sidebar navigation

A dark icon rail that adapts to your role, collapses to icons-only on desktop, and becomes a bottom bar on phones. Admin's extra sections tuck behind a More launcher — a floating panel of colored tiles (Organization, Calendar, Feedback, HR Request).

🎨

Themes & polish

Ten workspace color themes, remembered per user. Haptic feedback on supported devices, skeleton loaders, toast notifications, and reduced-motion support throughout.

👤

Profile & documents

Each person has a profile with photo, personal details and a documents card. Sensitive fields (DOB, address, phone, Aadhar) are only ever returned to authorized viewers.

🔗

Feedback & HR Request

Two sidebar shortcuts open admin-configured external forms (e.g. Google Forms or ClickUp forms) in an embedded popup. Admins set the links under Other Settings; leaving one empty disables that shortcut.

Design decisions worth knowing

  • Event log as source of truth — worked time is always recomputed from stored check-in/pause/resume events; the on-screen timer is display-only, so it can't drift or be tampered with.
  • Lazy finalization — stale sessions auto-close on the next read, so the 8-hour verdict never depends on a cron job firing (a real scheduler can still call the same finalizer).
  • One org-tree field — the whole hierarchy derives from managerId; upward and downward walks are cycle-safe and power announcements, approvals and team validation.
  • Security posture — identical error for wrong email vs wrong password, deleted users rejected even with valid tokens, password hashes never serialized, expired sessions handled in exactly one place.

Running it locally

npm install install dependencies npm run dev:all frontend + API against your Supabase Postgres database npm run lint oxlint over the project npm run build production build (deploys to Vercel with the serverless API)

Configuration lives in .env.local — Supabase Postgres connection string, JWT secret, the seed admin account, and optional reCAPTCHA keys. The first successful DB connection creates the schema and bootstraps the admin user and the default leave and employment types.
